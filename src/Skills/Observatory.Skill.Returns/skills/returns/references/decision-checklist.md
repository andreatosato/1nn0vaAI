# Lista di verifica per il reso

1. Ricava l'ID ordine esplicito dalla richiesta o dalla cronologia pertinente. Non selezionare mai un ordine di un altro cliente. Se il riferimento è ambiguo, chiedi quale ordine.
2. Usa l'ultimo motivo dichiarato, comprese le correzioni. Chiedi un chiarimento solo se manca un fatto che cambierebbe la valutazione; non far ripetere ciò che è già chiaro.
3. Difetto e ripensamento sono distinti. Affidati alla valutazione del tool, senza generalizzare un'esclusione outlet o inventare un'eccezione.
4. Conserva priorità, ID e versione o fonte della policy restituita.
5. Il rimborso si riferisce all'importo effettivamente pagato, non al prezzo pubblico di catalogo o listino.
6. Valutare l'ammissibilità non crea una bozza e non esegue un rimborso. Solo il tool separato, con conferma server e richiesta esplicita, può creare una bozza sintetica; la frase "confermo" non sostituisce l'autorizzazione.
7. Un errore o un rifiuto non è un'operazione riuscita. Spiega l'esito verificato in modo breve, senza esporre ragionamenti interni o dati inventati.
